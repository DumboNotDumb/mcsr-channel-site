Daily Dose of MCSR

Daily Dose of MCSR is a YouTube channel (on YouTube) that posts highlight Shorts and themed compilations from Minecraft speedrunning (MCSR Ranked). Every featured streamer is credited and linked in each video.

The channel uses a small private tool, "Daily Dose of MCSR Uploader," which uses the YouTube Data API and YouTube Analytics API only to upload the channel owner's own videos as private drafts, manage those videos, and read the channel's own analytics. It is used only by the channel owner and does not access anyone else's account.
